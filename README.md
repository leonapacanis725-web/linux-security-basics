# Linux Security Basics

A beginner cybersecurity project demonstrating basic Linux security analysis using command-line tools.

## Project Objective

The goal of this project was to practice inspecting a Linux system and understand how permissions, users, processes, and network services relate to system security.

## Skills Practiced

- Linux command-line navigation
- File permission analysis
- User and group enumeration
- Process inspection
- Network service inspection
- Least-privilege concepts
- Documenting security findings

## Commands Used

Some of the commands used during the project include:

`stat`
`chmod`
`id`
`groups`
`ps`
`ss`
`grep`

See [commands.md](commands.md) for examples.

## Security Findings

During the project, I examined:

- Linux file permissions and how `chmod` changes access.
- User and group membership, including privileged groups.
- Processes running under the root account.
- Listening network ports and their associated services.

See [findings.md](findings.md) for my documented observations and security takeaways.

## What I Learned

This project helped me understand that Linux security involves more than running commands. Results need to be interpreted and verified. I also learned how file permissions, privileged accounts, running processes, and listening services can be reviewed as part of basic system security analysis.
